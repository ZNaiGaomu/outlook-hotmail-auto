# Changelog

## v1.0.0 — 2026-08-14

First public source release of **outlook-hotmail-auto**.

- Headed browser edition with dashboard, local HTTP bridges, diagnostics, and optional Cloudflare temp-mail recovery
- Headless / protocol edition for leaner server deployments
- Example-only configuration files; live proxies, Azure client IDs, mailbox passwords, and tokens are not shipped
- Ubuntu installer, Xvfb runner, Docker image, and OAuth2 PKCE token capture
